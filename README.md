# Ethernet Communication Investigation and Traffic Analysis

## Overview
This repository contains the artifacts for an Ethernet communication investigation on a Linux platform. The project demonstrates network architecture understanding, MAC/IP addressing mechanisms, and TCP/UDP/ICMP protocol analysis using Wireshark and Linux networking tools.

## Repository Structure
* `docs/`: Contains the theoretical Study Report and practical Analysis Report.
* `screenshots/`: Visual captures of ARP, ICMP, TCP, and UDP network traffic.
* `wireshark/`: Raw `.pcapng` capture files for deep packet inspection.
